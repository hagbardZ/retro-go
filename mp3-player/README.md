
# MP3 Player for Retro-Go

This is a **MP3-Player** for the **Retro-Go** ecosystem.
The player uses libhelix, which is placed in mp3-player/components.
Only tested for ESP32P4.

## Recent updates:
  - ID3V1 + ID3V2 Tag support


## Features
- **File Picker** Y Key
- **Random Play** X Key
- **Pause** A Key
- **Repeat** B Key
- **Seek forward/rewind** left/right
- **Track forward/back** up/down

## Installation
1. Ensure your SD card is formatted and Retro-Go is installed.
2. Place your Mp3 files in the following directory:
   `music/`
